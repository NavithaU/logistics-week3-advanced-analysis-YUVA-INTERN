# Logistics Data Analytics — Week 3

**Task:** Advanced Data Analysis and Visualization in Logistics  
**Project title:** Logistics Data Analytics for Delivery Time Prediction and Cost Optimization Using Python

## Contents
- `data/logistics_week3_hypothetical.csv`: 120 simulated logistics shipments.
- `analyze_logistics.py`: Python script for exploratory data analysis and visualization.
- `visualizations/`: six generated charts.
- `outputs/`: descriptive statistics, correlation, and performance summary CSV files.
- `Week3_Advanced_Logistics_Analysis_Report.docx`: report with embedded visualizations and interpretations.

## Dataset disclaimer
The dataset is hypothetical/simulated for educational purposes and is not actual company data. Conclusions describe this sample only.

## Run in VS Code
1. Install Python 3.10+.
2. Open this folder in VS Code.
3. In Terminal, run `python -m pip install -r requirements.txt`.
4. Run `python analyze_logistics.py`.
5. Open the `visualizations` folder to view charts and `outputs` to view summary CSVs.

## Visualizations
1. Delivery-time histogram — distribution and spread.
2. Cost vs distance scatter plot — relationship and possible cost outliers.
3. Average delivery time by vehicle — group comparison.
4. Average cost by region — regional cost comparison.
5. Correlation matrix — pairwise linear associations.
6. Delivery-time trend — daily values and 7-day rolling average.
